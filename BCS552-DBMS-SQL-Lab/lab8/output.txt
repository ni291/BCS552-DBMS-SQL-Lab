=== Task 1: Show each region with the number of sales in it. Use GROUP BY region and sort by region.

SQL> SELECT region, COUNT(*) AS num_sales FROM shop_sale GROUP BY region ORDER BY region;
region  num_sales
------  ---------
North           2
South           2

=== Task 2: Show each region with the total amount in it. Use GROUP BY region and sort by region.

SQL> SELECT region, SUM(amount) AS total FROM shop_sale GROUP BY region ORDER BY region;
region  total
------  -----
North   23000
South   18000

=== Task 3: Show only the regions whose total amount is more than 20000. Use HAVING and sort by region.

SQL> SELECT region, SUM(amount) AS total FROM shop_sale GROUP BY region HAVING SUM(amount) > 20000 ORDER BY region;
region  total
------  -----
North   23000
